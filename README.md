# ANGEL SOLUTION
맞춤 제작 스튜디오 랜딩 + 프로젝트 쇼룸 관리자 CMS.

## 관리자 접근
관리자는 회원가입 없이 `/admin`에서 관리 코드를 입력합니다.
Vercel 환경변수 `ADMIN_PASSWORD`에 **관리 코드**를 설정하고 `SESSION_SECRET`에 32자 이상 무작위 문자열을 설정하세요.
관리 코드는 GitHub 소스코드, 클라이언트 코드, README에 저장하지 않습니다.
로그인 성공 시 서명된 HTTP-only 쿠키가 생성되고 `/admin/projects`로 이동합니다.
이 인증에는 회원 데이터베이스가 필요하지 않습니다.

## 데이터 보관
- **회원 DB:** 없음. 일반 방문자는 회원가입/로그인 없이 이용합니다.
- **관리자 인증 DB:** 없음. 서버 환경변수에 저장된 코드를 검증합니다.
- **시안 프로젝트와 고객 문의:** 정보의 영구 저장이 필요하기 때문에 현재 PostgreSQL(`DATABASE_URL`) 사용.
- **이미지 업로드:** Vercel Blob(`BLOB_READ_WRITE_TOKEN`) 사용.

관리 코드와 자료 저장은 서로 다른 기능입니다. DB 없이도 관리자 접속은 가능하지만, DB가 없다면 프로젝트 신규 등록/수정 및 고객 문의 저장은 작동하지 않습니다. `db/schema.sql`을 실행해서 테이블을 만들 수 있습니다.

## 실행
`npm install && npm run build && npm run start`

운영 전 관리 코드 로그인 시도 횟수 제한, 강력한 관리 코드, 비공개 콘텐츠 보안, 개인정보 보존 정책 등을 점검하세요.
